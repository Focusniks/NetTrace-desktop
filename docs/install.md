## Требования

| | |
|---|---|
| Система | Windows 10 или 11, 64-разрядная |
| WebView2 | Уже есть в Windows 10 и 11 |
| Права администратора | Не нужны |
| Для живого захвата | Драйвер [Npcap](https://npcap.com) |
| Память | Около 64 байт на пакет плюс таблицы потоков — см. [пределы](limits.md) |

Для чтения файлов PCAP и PCAPNG ничего, кроме самого NetTrace, не требуется.

## Установка

1. Откройте страницу [последнего релиза](https://github.com/Focusniks/NetTrace-desktop/releases/latest).
2. Скачайте `NetTrace_X.Y.Z_x64-setup.exe`.
3. Запустите файл. Программа ставится для текущего пользователя.

> **Важно.** Установщик не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение. Нажмите «Подробнее», затем «Выполнить в любом случае».

После установки файлы `.pcap`, `.pcapng` и `.cap` можно открывать в NetTrace двойным щелчком или через «Открыть с помощью».

## Npcap для живого захвата

Без Npcap NetTrace работает только с файлами. Чтобы захватывать пакеты:

1. Скачайте установщик с [npcap.com](https://npcap.com) и запустите его.
2. Снимите флажок **Restrict Npcap driver's access to Administrators only**, если хотите захватывать без прав администратора.
3. Завершите установку.
4. В NetTrace нажмите «Проверить снова» в списке интерфейсов или перезапустите программу.

Версия найденного драйвера показана внизу диалога «Захват пакетов». Если захват всё равно недоступен, смотрите [решение проблем](troubleshooting.md).

## Обновления

NetTrace проверяет новую версию при каждом запуске. Если она есть, появляется окно со списком изменений:

| Кнопка | Что делает |
|---|---|
| Установить и перезапустить | Скачивает обновление, проверяет его подпись, ставит и перезапускает программу |
| Позже | Закрывает окно до следующего запуска |
| Пропустить эту версию | Больше не предлагает именно эту версию |

Что важно знать:

- Пакет обновления проверяется по цифровой подписи. Неподписанный или изменённый пакет не установится.
- Если идёт захват, перед установкой он будет остановлен.
- Проверить вручную: **Помощь → Проверить обновления…**
- Отключить проверку при запуске: **Помощь → Проверять обновления при запуске**.
- Когда и с каким результатом была последняя проверка, видно в окне **Помощь → О программе**.

При проверке программа обращается только к GitHub. Сведения о вас и ваших захватах не передаются — подробнее в разделе [безопасность и приватность](privacy.md).

## Удаление

**Параметры Windows → Приложения → Установленные приложения → NetTrace → Удалить.**

Настройки интерфейса хранятся в профиле пользователя и при удалении не трогают ваши файлы захвата.
