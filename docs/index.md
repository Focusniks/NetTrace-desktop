## Проверка оформления

Фильтр `ip.addr == 10.10.1.15 && tcp.port == 443` и клавиши <kbd>Ctrl</kbd>+<kbd>F</kbd>.

```text
tcp.analysis.retransmission && ip.addr == 10.0.0.0/8
```

| Поле | Тип | Описание |
|---|---|---|
| `ip.addr` | ipv4 | Адрес источника или назначения |
| `tcp.port` | uint | Порт источника или назначения |

> **Примечание.** Обычная заметка.

> **Важно.** Предупреждение.
