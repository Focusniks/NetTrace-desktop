# Журнал изменений

Все заметные изменения NetTrace. Раздел версии показывается в окне обновления
и в описании релиза на GitHub, поэтому пишите его для пользователей.

Перед выпуском опишите изменения в разделе «Unreleased» и выполните
`npm run release -- X.Y.Z` в `apps/desktop` (подробнее — docs/RELEASING.md).

## [Unreleased]

### Добавлено
- «Содержимое потока»: данные TCP- или UDP-потока целиком, в правильном порядке, как текст
  или hex, для обоих направлений или одного. Повторные передачи убираются, сегменты не по
  порядку переставляются, потерянные и обрезанные участки отмечаются. Клик по строке
  выделяет её пакет. Открывается из контекстного меню пакета, окон «Потоки» и «Соединения»
  и меню «Анализ».
- Сохранение данных потока в файл (без заголовков пакетов); если часть данных не попала
  в захват, программа сообщает, сколько байт отсутствует.

### Исправлено
- При закрытии приложения во время захвата временный файл захвата удаляется сразу.

## [1.0.1] - 2026-10-10

### Добавлено
- Поиск подсвечивает найденное: поле в дереве деталей и байты в hex-просмотре.
- Колонка «Конец» в окне «Соединения».
- I/O-график и конструктор фильтра работают и с UDP-потоками.
- В окне «О программе» видно, когда и с каким результатом проверялись обновления.
- Кнопка «Проверить снова», если Npcap установлен при открытом приложении.

### Исправлено
- Интерфейс полностью на русском: ошибки, метки диаграммы последовательности, служебные строки дерева пакета.
- Конструктор фильтра сбрасывает значение при смене поля, если оно не подходит.
- Переход к пакету из развёрнутой панели инструментов показывает список пакетов.
- Подсветка при перетаскивании файла в окно.
- Долгий живой захват больше не держит память под давно затихшие соединения.
- Временный файл живого захвата создаётся безопасно (только новый, со случайным именем).
- Ключ подписи обновлений доступен только шагу подписи при выпуске; добавлена проверка уязвимостей зависимостей.

## [1.0.0] - 2026-10-10

### Добавлено
- Первый публичный выпуск NetTrace.
- Открытие PCAP и PCAPNG, ленивая загрузка больших файлов и фоновая индексация.
- Список пакетов, дерево протоколов и hex-просмотр с подсветкой байтов полей.
- Разбор Ethernet, VLAN, ARP, IPv4/IPv6, ICMP, TCP, UDP, DNS, DHCP, HTTP, TLS (SNI, сертификаты), NTP.
- Анализ TCP: повторные передачи, дубликаты ACK, нулевое окно, потери, RTT.
- Фильтр отображения с автодополнением и визуальный конструктор фильтра.
- Поиск по IP, MAC, порту, протоколу, строке, байтам, домену, HTTP Host, TLS SNI.
- Потоки, диаграмма последовательности, узлы, соединения, статистика, временная шкала, технические индикаторы.
- Работа с очень большими захватами: таблицы узлов, соединений и потоков подгружаются по мере прокрутки, сортировка и поиск выполняются без загрузки всех строк; компактное хранение — около 0,5 КБ на пакет даже в худшем случае.
- Захват трафика в реальном времени через Npcap с выбором интерфейса.
- Установщик для Windows и автоматические обновления с проверкой цифровой подписи.
